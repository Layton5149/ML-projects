# ML-projects

cataractsCNN - This project builds a binary image classification model capable of detecting cataracts from eye images. It uses a standard CNN architecture and trains on labeled medical images.

AnimeReccomendation - This project explores how machine learning can be combined with web development to deploy a user friendly medium to interact with a ML model. a knn model is used to create a recommender system for users to get suggestiosn for new animes to watch based on liked anime.
